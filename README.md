# G152-TeamSync_AI
TeamSync AI is a web-based project and task management platform designed to help student and professional teams manage their work in an organised way. It provides a common platform where team members can create projects, assign tasks, set deadlines, share updates, and monitor overall progress. Users can manage their tasks through a simple Kanban board that shows different stages of work, such as To Do, In Progress, In Review, and Done. The platform also includes features like team collaboration, task comments, notifications, and deadline reminders. An AI assistant helps users create task lists from project descriptions and generate short progress summaries. TeamSync AI aims to improve teamwork, save time, reduce confusion, and make project management easier and more efficient.
